# Mya Nyo Tea Website — Simple English Version of the Specification

---

## 1. Software Name

**Mya Nyo Tea Website**
(An online sales website for Mya Nyo Herbal Tea)

---

## 2. Purpose

This software is an online product sales website for **Mya Nyo Herbal Tea**.

- **Visitors** can view products and buy them.
- **Admin** can manage the products.

---

## 3. Visitor Side (What customers can do)

| # | Feature | Details |
|---|---|---|
| a | **View products** | See product image, name, price, size, and flavor |
| b | **Filter products** | Filter products by category |
| c | **Buy / Order** | Order in two ways:<br>• **Order via Viber**<br>• **Call to Order** (by phone) |
| d | **Stock status** | Each product shows **IN STOCK** or **OUT OF STOCK** |
| e | **Language switch** | Switch between **English (EN)** and **Myanmar (MM)** |

---

## 4. Admin Panel (What the admin can do)

| # | Feature | Details |
|---|---|---|
| a | **Add new product** | Enter name, image, price, size, flavor, and category |
| b | **Change price** | Edit the price of any product |
| c | **Remove / Delete product** | Delete a product from the site |
| d | **Change stock status** | Switch a product between IN STOCK and OUT OF STOCK |
| e | **View product list** | See all products in one list |

---

## 5. Design & Branding

| # | Requirement | Details |
|---|---|---|
| a | **Brand display** | The name **"Mya Nyo"** must be shown clearly on the website |
| b | **Mobile responsive** | The site must work well on **both phones and computers** |

---

## 6. Technical Specifications

| # | Requirement | Details |
|---|---|---|
| a | **Modern technology** | The website must be built with modern technology |
| b | **HTTPS / SSL** | The site must use a secure connection (HTTPS/SSL) |
| c | **Login system** | The Admin Panel must have a login system |
| d | **Database** | Product information must be stored in a database |

---

## 7. Deliverables (What must be handed over)

| # | Deliverable | Details |
|---|---|---|
| a | **Working website** | A fully working, ready-to-use website |
| b | **Admin Panel** | A working admin dashboard |
| c | **User Manual** | A guide on how to use the website |
| d | **Source code** | The complete source code of the project |

---

## In One Sentence

> Build a simple, mobile-friendly online tea shop for **Mya Nyo Herbal Tea** where visitors can browse products (in English or Myanmar), check stock, and order via **Viber or phone** — and where the admin can add, edit, delete products, change prices, and update stock status through a secure login-protected panel, with all product data stored in a database.
